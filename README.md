**Thiago Robade**

Este repositório registra minha evolução prática nos fundamentos da linguagem Java,
com exercícios organizados por tema e soluções desenvolvidas ao longo da trilha.

## 📚 Sobre a trilha

Este projeto contém as resoluções da trilha
**[Praticando Java](https://cursos.alura.com.br/app/learning-guide/alura/praticando-java)**,
da Alura. O objetivo é consolidar conceitos essenciais da linguagem por meio de
desafios práticos, indo dos tipos primitivos até coleções e Streams.

## 🚀 Como executar

Cada exercício possui uma classe Java independente. Para compilar e executar um
exercício do primeiro módulo:

```bash
javac 01-variaveis-e-tipos/src/Ex01DeclarandoValoresAVariaveis.java
java -cp 01-variaveis-e-tipos/src Ex01DeclarandoValoresAVariaveis
```
